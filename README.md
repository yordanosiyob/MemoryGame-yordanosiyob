# MemoryGame

## Beskrivning
MemoryGame är ett interaktivt kortspel utvecklat med HTML, CSS och JavaScript. Spelets mål är att matcha kort genom att klicka på dem för att vända och identifiera par. Spelet inkluderar en timer, räknare för antal försök samt en starta om-funktion, och korten placeras slumpmässigt vid varje spelstart.  

---

## Funktioner
- Kort vänds vid klick  
- Timer med val: 15s, 30s, 60s  
- Räknare för antal försök  
- Starta om-funktion  
- Kortbilder initieras från en array och slumpas vid varje spelstart  

---

## Tekniker
- HTML5  
- CSS3 (Flexbox, responsiv design)  
- JavaScript (DOM-manipulation, event listeners, arrays och slumpfunktioner)

## Instruktioner för att köra spelet

1. Klona eller ladda ner projektmappen.  
2. Öppna "index.html" i en webbläsare.  
3. Spelet fungerar direkt med vändbara kort, timer, räknare för försök och starta om-funktion.

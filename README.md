# MemoryGame

An interactive memory card game built with HTML, CSS and JavaScript. Match pairs of cards before the time runs out.

**Live demo:** https://yordanosiyob.github.io/MemoryGame-yordanosiyob/

## Features
- Cards flip on click and are shuffled at the start of each game
- Selectable timer: 15, 30 or 60 seconds
- Move counter
- Restart function

## Tech stack
- HTML5
- CSS3 (Flexbox, responsive design)
- JavaScript (DOM manipulation, event listeners, arrays)

## My contribution
The HTML, CSS and images were provided as a template by the course instructor. I developed all of the JavaScript and game logic, including card flipping, shuffling, the timer and the move counter.

## How to run
Open the live demo, or clone the repository and open `index.html` in a browser.
